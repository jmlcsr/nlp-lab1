| 最长文本 | 5134 词 |
| Training Set | 9157（80.0%） |
| Validation Set | 1145（10.0%） |
| Test Set | 1145（10.0%） |
| 划分方式 | 先 `sample(frac=1, random_state=42)` 随机打乱，再分层 8:1:1 |

**两个必须在报告中讨论的点：**

1. **类别严重不均衡。** sports 占 75.1%，因此 Accuracy 存在约 **75% 的"地板"** ——
   一个永远输出 sports 的平凡基线就能拿到约 0.75 的 Accuracy。
   这说明**必须同时看 Macro-F1**，也解释了作业为什么要求两个指标都报告。

2. **文本极长，而作业规定 BERT 的 `max_length=64`。**
   平均 637 词（转成 subword token 通常 800+）远超 64，
   意味着 **BERT 只能看到每篇文档开头约 8% 的内容**。
   这个参数是作业硬性规定的，必须遵守，但要在报告中量化截断比例并讨论影响。

#### 2026-10-07 下载排查记录（四种方式均未成功）

| # | 方式 | 结果 |
| --- | --- | --- |
| 1 | `curl` **直连** `http://nlp.stanford.edu/...` | 能连上（拿到 308 重定向 + 822 MB 文件头），但限速 **12 KB/s → ETA 19 小时** |
| 2 | `curl -x http://127.0.0.1:7897`（走代理） | **0 字节**，生成空文件 → `zipfile.BadZipFile` |
| 3 | Python urllib + 系统代理，`http://` | **HTTPError 502 Bad Gateway**（502 由代理返回） |
| 4 | Python urllib + 系统代理，`https://` | **SSLEOFError: UNEXPECTED_EOF_WHILE_READING**（TLS 握手阶段被中断） |

#### 结论与线索

- 同一代理访问 `pypi.org` / `download.pytorch.org` / `github.com`（**均 HTTPS**）
  **全部正常，5~7 MB/s** → 代理本身可用。
- 但访问 `pypi.tuna.tsinghua.edu.cn` 时也报过**同一个 `SSLEOFError`**。
- **不走代理**时 Stanford 反而能建立连接并开始传输 → 说明不是"境外站点被掐"，
  而是**该代理节点到 Stanford 的线路不通**。
- 综合：直连太慢、代理不通，**结论是必须换源（镜像）**。

> Windows 设置 → 网络和 Internet → 代理 里关闭"手动设置代理"。
